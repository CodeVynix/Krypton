Krypton Docs

The minimal Windows browser: an address bar, tabs, and nothing you didn't ask for.

How it works

Every tab owns exactly one Chromium page (ChromiumWebBrowser). The window frame, tab strip, and toolbar are native WinForms — no web tech in the app shell. Built-in pages live on the krypton:// scheme:

  • krypton://new-tab — this dashboard (bundled newtab.html)
  • krypton://docs — this page (bundled docs.html)

Page events (address, title, loading) arrive on background threads and are marshalled to the UI thread before touching any control — the shape of it:

private void Browser_AddressChanged(object? sender, AddressChangedEventArgs e)
{
    // CEF thread: never touch controls here.
    Ui(() => addressBar.Text = e.Address); // marshalled to the UI thread
}

Address bar

  • Type a web address to go there (https:// is added when missing).
  • Type anything else to search it on Google.
  • While typing, matching hosts complete inline: Tab accepts, Esc reverts, Enter goes.
  • Ctrl+L jumps back here from anywhere.

Tabs

  • + opens a tab, × closes one. Closing the last tab exits Krypton.
  • Crowded tabs shrink to share the strip — scroll them with the mouse wheel.

Right-click menu

  • Back, Forward, Reload — greyed when there is nowhere to go.
  • Print, Save as (page HTML), View page source, Inspect.
  • On links: open in a new tab, save the target, copy the address.
  • On images: open in a new tab, save the image, copy the image itself or its address.

New-tab dials

Four shortcuts: YouTube, GitHub, Gmail, Maps. Clicking the address bar selects everything, so replacing it is one keystroke.

System requirements

Minimum — Windows 10 (1809 or newer, 64-bit), dual-core x64 processor, 4 GB RAM, about 800 MB free disk space (app, browser engine, profile and cache), and the VC++ 2022 x64 runtime. The app is currently unsigned, so Smart App Control may block it until the signed release lands.

Recommended — Windows 11 (64-bit), quad-core processor or better, 8 GB RAM, an SSD, and a 1080p or higher display. More RAM mostly helps when many heavy tabs (video, docs, maps) stay open at once.

When something looks wrong

  • A blank page after stopping a load: it recovers to the previous page, or a fresh New Tab.
  • A crash leaves evidence in %LocalAppData%\Krypton\crash.log — attach it to your issue report.
